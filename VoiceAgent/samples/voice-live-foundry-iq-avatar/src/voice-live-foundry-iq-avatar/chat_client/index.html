Voice Live Foundry IQ — standalone client

Browsers can't set the Foundry Authorization header. To talk to a hosted agent from this page, run the bundled local proxy in another terminal: 
python proxy.py --foundry https://<account>.services.ai.azure.com/api/projects/<project> --agent voice-live-foundry-iq-avatar
then point the WebSocket URL below at ws://localhost:8765/invocations_ws. The proxy injects Authorization: Bearer <az token> on your behalf. Direct Foundry data-plane URLs are blocked here because the browser can't authenticate them; authenticated wss:// reverse proxies remain valid.
