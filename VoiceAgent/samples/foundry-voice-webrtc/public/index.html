Quick setup & connection notes
  1. Create a Voice agent in your Foundry project using the Microsoft quickstart. WebRTC requires additional transport availability.
  2. Install Azure CLI, open a normal PowerShell window, and run az login. Use the tenant/subscription containing your project. Keep your project endpoint and agent name in .env. Agent Service requires Microsoft Entra ID, not a resource API key; no client secret is needed. Your signed-in account needs access to the Foundry project or agent.
  3. For WebSocket, configure mono PCM16 audio at 24 kHz, server-side turn detection with automatic responses, and speech transcription in Foundry. Open this page on localhost, choose a connection, and allow the microphone.

Bearer tokens stay on the backend. Run the server as the same Windows user who ran az login, with outbound network access. Check authentication and session startup with python check_websocket.py.
